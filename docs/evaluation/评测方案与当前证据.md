# 评测方案与当前证据

本文区分“候选探索”和“正式评价”。候选数据可以用于验证程序是否工作；只有人工确认必要证据、冻结语料/问题/参数并完成覆盖要求后，才允许形成正式结论。

A01–A16 的当前证据、状态与剩余门槛见[验收证据索引](./A01-A16验收证据索引.md)。其中工程测试通过不替代人工 qrels、正式问答评测或 A14 真实语料验收。

## 检索对照

| 方案 | 检索流程 |
|---|---|
| R1 | 向量召回 |
| R2 | 向量 + 关键词召回，使用 RRF 合并 |
| R3 | R2 + Reranker |

三种方案使用相同问题、范围、版本和索引代，按唯一物理页排序后计算前 8 页指标。必要证据组允许包含多个等价页面/片段；每题 Evidence Recall@8 为命中的必要证据组比例，主结果对可评分题宏平均。补充报告 Hit@8、MRR、检索延迟和请求成本。R3 的目标门槛是建议值，不代表预设结论；R3 不优于 R1 时应如实报告。

离线评分器不访问模型或数据库。所有带有效必要证据的 qrels 题都进入宏平均分母；缺失排名记零分，并在 `questions_missing_rankings` 中列出。若任何可评分题缺少延迟或成本，整体对应字段为 `null`。正式结论还要求三种策略均覆盖全部可评分题、运行记录语料哈希与 qrels 一致、人工标注状态为 `confirmed`，且运行记录明确标记 `evaluation_scope=confirmed-evaluation` 和 `official_claim_allowed=true`。

## 标注流程

原始 Q1–Q8 保持不变；新增 Q9–Q24 分为 8 条可回答、4 条证据不足和 4 条范围/安全题。候选证据附有来源 PDF 哈希、物理页和原文摘录，校验器验证它们与当前 PDF 一致。Q1–Q24 的人工评阅状态目前仍待确认，4/2/2 留出分配仍是提案；机器校验不替代用户或导师确认。

为便于逐题核阅，已生成 [Q1–Q24 人工复核表](../../work/reviews/m6-annotation-review/人工复核表.md)。它逐题列出原始问题或补充候选、现有证据线索与待填写的裁定栏；填写这份复核表不会自动更改 qrels、确认标注或启动正式评分。

正式 qrels 至少应确认：范围模式、可回答性、必要证据组、答案要点、允许同义表达、禁止推断、问题类别、评阅人和时间、开发/留出分组及数据哈希。负例和安全题用于回答/Agent 验收；没有必要证据的题不计入检索 Evidence Recall 分母，但应进入缺证和安全处理评测。
