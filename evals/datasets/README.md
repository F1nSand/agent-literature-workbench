# 评测资料

首批资料直接引用项目目录中的原始 `示例论文文档与问题集/` 文件，不另复制 PDF。`sample-corpus-manifest.json` 固定了 4 篇论文和 8 道问题的哈希及 PDF 物理页数。

使用工作区随附的 `pypdf` 检查了物理页和提取文字量：4 篇均每页提取到超过 40 个字符（78/78 页），未发现纯图像页。这说明该批输入无法覆盖纯扫描件 OCR 测试。已另建一页图像型合成夹具，见 [`fixtures/README.md`](./fixtures/README.md)；M0 云 OCR 探测识别出该页完整可见文本，但仅为单页烟雾测试，未测 bbox，也不能代表真实扫描集准确率。不能以有文字层推断公式、图表内容已经解析准确。

已对照提问集渲染查看部分页面：公式题的 `pass@k` 估计式在 `01‑Cost‑Effective‑Agent‑Harnesses.pdf` 物理第 6 页；中文架构流程图在 `04‑中文‑大语言模型智能体出行日志.pdf` 物理第 5 页；`02‑ModelScope‑Agent.pdf` 第 10 页包含图 4–6，其总体架构图在第 3 页。候选证据和逐题范围说明见 [`sample-question-evidence-review.md`](./sample-question-evidence-review.md)。该文件不是冻结答案集，也不构成正式评测标注；印刷页码与必要证据组仍需用户/导师复核。

资料授权：用户指示直接将项目目录资料用于该毕设项目，并确认允许论文云端处理。此许可不等同于允许把论文公开发布到 Git 远端或其他公开服务。
